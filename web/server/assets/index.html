姿态与校准边界

静置约 3 秒后自动估计零偏，之后仅在低运动窗口保守跟踪；也可手动重校。极慢匀速转动可能被误认为零偏。重置保留零偏，刷新后重新估计。

六轴融合由浏览器 Worker 计算。无磁力计，Yaw 无绝对北向且仍会漂移；重力辅助横滚/俯仰。自动静置判断不是运动真值，初始匀速转动或校准后低于约 0.11°/秒的转动仍可能被当作零偏。没有航向锁定或角速度死区。重置按当前重力对齐，不将倾斜归零。

模型仅为坐标示意，不是产品外形。运动加速度、振动与 ≤50 Hz 抽取影响精度，不用于导航或标定。断流冻结，重连或时间戳跳变后重新对齐；新采集会话清除零偏并等待重新静置。
